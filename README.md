🚀 One-Tap Study Buddy

GDG TechSprint 2026 Submission | Team: Overclocked

One-Tap Study Buddy is a multimodal AI tool designed to combat information overload. It leverages Google Gemini 1.5 Flash to transform long-form PDFs and YouTube videos into digestible summaries and interactive quizzes instantly.

👤 Team Details

Team Name: Overclocked

Team Leader: Arya Mittal

Problem Statement: Open Innovation

📺 Demo Video

🌟 Key Features

One-Tap Processing: Upload a PDF or paste a YouTube URL to get instant insights.

Multimodal Analysis: Processes video transcripts and text documents with equal precision.

Recursive Summaries: Intelligent TL;DRs that capture high-level concepts and deep-dive details.

Auto-Quiz Generation: Uses Gemini to create MCQ tests for active recall, helping you master material faster.

Grounded Chat: A "Talk to your document" feature with zero hallucinations—answers are derived strictly from your source material.

🛠 Tech Stack

AI Engine: Google Gemini 1.5 Flash (1M+ Token Context Window)

Frontend: React.js, Tailwind CSS

Icons: Lucide-React

Infrastructure: Firebase (Auth, Firestore, Hosting)

🚀 Getting Started

Prerequisites

Node.js (v18 or higher)

A Google Cloud Project with the Gemini API enabled

Installation

Clone the repository:

git clone [https://github.com/aryamittal06/one-tap-study-buddy.git](https://github.com/aryamittal06/one-tap-study-buddy.git)
cd one-tap-study-buddy


Install dependencies:

npm install


Set up environment variables:
Create a .env file in the root directory:

VITE_GEMINI_API_KEY=your_api_key_here


Run the development server:

npm run dev
